# CDT-320 핵심 원칙 (항상 준수)

작업 시작 전·중·후 항상 확인하는 고정 원칙. 상세 코딩 규칙은 [AGENTS.md](../AGENTS.md), 진입점은 [CLAUDE.md](../CLAUDE.md).

## 1. CDT-310 알고리즘이 기준 (절대 위배 금지)
- 모든 비전/검사 알고리즘의 정답은 CDT-310. 코어(`CDTInspector.BottomInspect`, `QMC_FindChippingNForeign`, `ContaminationDetector`, FindDie/Chipping 등)는 **건드리지 않는다.**
- 개선은 **코어 밖 보강만** — 마스크/후처리(라인·종횡비 필터, 면적가중 중심 등)/성능(다운스케일·병렬).
- 보강 후 **무회귀 확인**: 순차 결과 == 개선 결과가 동일해야 정상.

## 2. Sim은 항상 실제와 동일하게 동작
- **경로/프로토콜/값**이 실제 장비와 같아야 함. Sim 테스트가 실제와 갈리면 검증이 무의미.
- 예: 실제가 `INSPECTASYNC×4 → INSPECTRESULT`(병렬)면 Sim 셀프런도 같은 명령을 써야 병렬 경로가 실제로 검증됨.
- 값도 일치: `SimCamera` 해상도/프레임을 실제 카메라와 맞춤(더미 640×480 방치 금지).

## 3. 통신 와이어 포맷 안정
- 기존 명령의 와이어 포맷을 임의로 바꾸지 않는다. **동작만 조정**, 부가 데이터는 in-process 스토어로.
- 불가피하면 **선택적 뒤 인자 추가**(하위호환)만 — 예: `INSPECTASYNC|insp|chip_uid|picker`.

## 4. 그랩은 물리 제약 = 병렬화 대상 아님
- 픽커당 그랩 1회는 물리적으로 고정. **줄일 수 없다.**
- 병렬화 대상은 **검사(데이터 처리)뿐** — 그랩은 그대로, 처리만 동시에.

## 5. 스레드 안전 (병렬 시)
- 검사기 인스턴스는 가변 상태(`Last*`, `_libInspector`) 보유 → 한 인스턴스를 동시 호출하면 레이스.
- 병렬은 **픽커별 독립 인스턴스** + 필요한 설정 복제(`CopyInspectorConfig`). 공유 스토어 병렬 기록 안전성 확인.

## 6. 빌드/작업 트리
- 작업/빌드 기준 저장소가 별도(예: `V:\Source`)일 수 있음 → **편집이 어느 트리에 반영되는지 먼저 확인**(동기화가 편집을 되돌릴 수 있음).
- 작업 시작 시 `git status --short`. 사용자가 요청 안 한 기존 변경은 되돌리지 않음. 관련 파일만 수정.
- 컴파일 검증은 별도 `OutDir` 빌드(실행 중 DLL 잠금 회피).

## 7. AGENTS.md 코딩 규칙 (요약)
- **Designer**: 컨트롤 선언/배치는 `.Designer.cs` 인라인, 로직은 일반 `*.cs`. 클래스명=파일명, `partial`.
- **예외**: 함수는 `try/catch/finally`. `catch{}`로 무시 금지. 실패 시 로그 + (UI)메시지박스 / (Sequence)Alarm.
- **모션/시퀀스**: 비동기 `Task<int>`(성공 0/실패 -1). UI 스레드에서 `Thread.Sleep`·무한 while 금지. 이동 명령 후 반드시 결과 확인 + Wait InPosition. 시뮬에서도 완료 확인 생략 금지.
- **명명**: 컨트롤 prefix(btn/lbl/txt/cmb/chk/grid…), 이벤트=`컨트롤명_이벤트`, 메소드는 동사 시작, bool은 `Is/Can/Check`.
- **인코딩**: 모든 파일 UTF-8. 깨진 한글은 작업 범위 내 복원(불확실하면 사용자 확인).
- **JSON**: pretty UTF-8(`JsonPrettySerializer.WriteObject`).
- **신규 .cs**: `.csproj`에 수동 등록(명시적 Compile Include 방식).

## 8. 검증 습관
- 비트리비얼 작업엔 마지막에 **검증 단계** — 무회귀 확인, 순차=병렬 동일성, 실데이터(`Y:\PersonalStorage\김영남\CDT`) 대조, 빌드 확인.
- 파라미터 튜닝은 합성이 아닌 **실제 이미지**로 최종 확정.
