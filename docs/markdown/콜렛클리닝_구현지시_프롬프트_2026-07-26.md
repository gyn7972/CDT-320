## 0. 절대 준수 사항 (작업 규칙)

1. **MachineController.cs 동시 작업 충돌 방지 (최우선)**

   - **새 메서드 추가(append)만 허용.** 기존 멤버 수정/삭제/재정렬/리포맷 금지.
   - 내 기억과 다른 코드가 보여도 **절대 롤백하지 않는다** (다른 AI의 작업분이다).
   - 전체 덮어쓰기(Write) 금지 — 문자열 치환(Edit)만 사용.
2. **UI 컨트롤은 전부 Designer 인라인**
   - 모든 컨트롤: 필드 선언 + `InitializeComponent()` 안에 표준 직렬화 형태
     (`new` → 속성 → `Controls.Add` → `SuspendLayout/ResumeLayout/PerformLayout`).
   - Visual Studio 디자이너 뷰에서 열리고 보여야 한다. **런타임 동적 컨트롤 생성 금지.**
3. **AGENTS.md 준수**
   - **Clean/Rebuild 절대 금지** (OutputPath가 운영 영역 `D:\CDT-320`를 가리킴).
   - 검증 빌드는 별도 OutDir만: `MSBuild QMC.CDT-320.sln /t:Build /p:Configuration=Debug "/p:Platform=Any CPU" /p:OutDir=<임시폴더>\`
   - 파일 인코딩 UTF-8 BOM + CRLF. 로그는 한국어(`QMC.Common.Log.Write("Main"|"Calibration","SYSTEM",src,msg)`).
   - 시퀀스는 `Task<int>`(0=성공) 규약, `async void` 금지, 알람은 Fail 1회(중복 발행 금지),
     이동은 명령→결과→완료대기 3단계, 인터락은 최후 안전망(우회 금지).
4. **안전 필수**: 시퀀스 시작 시 안전 위치 확인/이동 필수. 클리닝 중 미사용 픽커 헤드는 Z Avoid 유지.

## 2. 신규 파일 (기능 본체는 전부 새 파일)

### 2-1. `Equipment/Calibration/ColletCleaningData.cs`

`ColletCleaningSettings` ([DataContract], Clone() 포함):
- 대상 선택 기본값: Front/Rear × 콜렛 4,3,2,1 (bool 8개, 기본 true)
- Z 동작: `CleanVelocity`, `CleanAcceleration`, `CleanDeceleration`,
  `ContactZUserOffset`(**+ = 상승 / − = 더 하강** — 사용자 확인된 부호 규약),
  `MaxExtraPressDepth`(과압 방지: 계산 접촉Z 대비 추가 하강 허용 한계),
  `ArriveDwellMs`(도착 대기), `CleanPressCount`(누름 반복 횟수), `RepeatLiftHeight`(반복 시 상승 높이, +값)
- 높이(티칭 제외분): `DieHeight`, `RimHeight`, `FilmHeight`
  — 기존 ColletCal 설정(ColletDieCalThickness/ColletFilmThickness/ColletRimOffsetFromFlat)과 값 연동 가능하면 초기값으로 가져오고, 독립 편집 허용
- 재시도: `MaxRetryCount`(클린→검사 반복 한계)
- 셀 정책: `AllowPlaceOnCleanedCell`(bool) — true면 클린한 셀에도 NG die 배치 허용, false면 배치 대상에서 제외
- 교체알람 후: `DisablePickerOnReplaceAlarm`(bool) — 해당 픽커만 생산 제외하고 계속 운전
- 자동 트리거(각각 독립): `UseTriggerOnWaferExchange`+`WaferExchangeInterval`(교체 n회마다),
  `UseTriggerOnProcessCount`+`ProcessCountInterval`+단위(die/wafer), `UseTriggerOnAutoStart`
- 검사 판정 파라미터는 두지 않는다 — **비전이 주는 OK/NG를 그대로 사용** (사용자 확정)

`ColletCleaningHistory`: (side, colletNo)별 `LastCleanedAt`, `TotalCleanCount`, `LastResult(Ok/Ng/ReplaceAlarm)`, `LastRetryUsed`

`CalibrationData.cs`에 `[DataMember] public ColletCleaningSettings ColletCleaning`,
`[DataMember] public ColletCleaningHistory ColletCleaningHistory` 추가 (AutoCalibration 패턴 동일).

### 2-2. `Sequencing/Calibration/ColletCleaningSequence.cs`

배치 시퀀스 (AutoCalibrationSequence 모델: plain class + ProgressChanged + RequestImmediateStop + ResumeKey).
수동(다이얼로그)과 자동(코디네이터) 공용 — 생성자에 (context, settings, 선택 픽커 목록, SequenceRunMode).

**배치 흐름 (사용자 확정: 전부 클린 → 전부 검사 → NG만 재시도):**
```
[Phase 1 CLEAN]   선택 픽커 전부 순서대로(4→3→2→1, Front→Rear):
                  셀 선점 → NG StageY 셀 위치 이동 → 픽커X 정렬 → 해당 헤드 Z 누름 사이클 → Z Avoid
[Phase 2 INSPECT] BottomView(다이 검사존)로 이동 후 선택 픽커 전부 순서대로 콜렛 검사(비전 OK/NG)
[Phase 3 RETRY]   NG 픽커만 Phase1→2 반복, MaxRetryCount 소진 시
                  COLLET-CLEAN-REPLACE 알람("콜렛 교체 필요") + DisablePickerOnReplaceAlarm 처리
```

**세부 규칙:**
- 시작 안전검증: 본인+반대 픽커 Avoid, OutputVisionX Avoid, 피더/리프터 Avoid (ColletCal 검증 재사용)
- 리소스: `OutputNgStageArea` + 픽커 work zone(Output) lease. 자동 실행 시 코디네이터 게이트 준수
- **NG빈 부재 시**: 알람 아님 — 스킵 + 경고 로그, 다음 트리거에서 재시도 (전용 결과코드로 구분)
- **셀 선점**: NG 다이맵 **맨 끝→앞** 방향 소비. 셀에 die가 있으면 알람 발생 + 그 셀 사용 안 함.
  커서는 **NG빈 교체 시 리셋**(빈 ID 변경으로 판별). `AllowPlaceOnCleanedCell=false`면 사용 셀을 배치 제외 마킹
- **접촉 Z 계산**: `접촉Z = NG Place 티칭Z − DieHeight − RimHeight − FilmHeight + ContactZUserOffset`
  (부호: + 상승 / − 하강). `MaxExtraPressDepth` 초과 하강은 차단(알람).
  ⚠ 첫 적용 시 한 픽커 저속으로 PlaceZCal flow 실측 로그와 대조 검증 후 전개할 것
- **누름 사이클**: 클리닝 전용 속도/가감속으로 접촉Z 하강 → `ArriveDwellMs` 대기 →
  `RepeatLiftHeight`만큼 상승 → × `CleanPressCount` 반복 → Z Avoid 복귀
- StageY 이동 시 NG 클램프 리프트 UP 규칙 준수(축 이동 관문이 강제함 — 우회 금지)
- **CycleStop/정지**: 진행 중 누름 사이클만 완료 → Z 안전 복귀 → 중단. SequenceResumeStore 기록
- 완료/실패 시 이력(History) 갱신 + CalibrationData 저장. 알람은 Fail 1회
