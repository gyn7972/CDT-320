### B항목 해소
- **B1 (기구)**: 1-A의 Z 목표 = 최종 촬영높이. 기존 FlyingZDownMode=ToBottomPosition이 이미 같은 높이로 선행 하강 + 그 상태로 X 피치 이동을 수행하던 선례와 동일 평면. 50mm는 파라미터로 현장 조정 가능. 접근 시작 시 잔여가 이미 임계 이하인 짧은 피치에서는 X 이동 전에 Z+T가 먼저 완료될 수 있음 — 동일 평면·M5 태그 허용 범위.
- **B2 (T die 보유)**: 기존 도착 후 동일 T 회전의 시점 앞당김일 뿐, 진공 유지 로직 무접촉.
- **B3 (X 실패 시 정리)**: ObservePendingBottomZDownTasks로 선행 Task 관찰 정리, 축 수습은 기존 실패 처리 경로(Z Avoid 복귀) 위임 — Z 이동 중 X 재이동 신규 경로 없음.
- **B4 (AF와 join 순서)**: join은 AF보다 앞(**AF 미실행 경로엔 Z 재검증이 없어 Z 보증은 이 순서가 유일** — 조사로 확인). 충족.
- **B5 (5% 스케일)**: X 50mm@5%≈20s vs Z 하강(수 mm~십수 mm)@5% — X가 항상 더 길어 join 대기 0 수렴 예상. join 미완료여도 join이 대기하므로 안전.

### 인터락 전수 점검(A1~A6) — 전 항목 통과

## 5. 별도 이슈 (범위 외 발견)

1. **PREDOWN-WAIT/-POS Fail 코드 통합**: join 실패가 동기 재시도 후 `-CMD` 하나로 수렴(사유는 메시지에 포함). 알람 사전에서 WAIT/POS를 개별 감시하면 -CMD로 보임.
2. **1-A는 FlyingZDownMode와 독립**: Mode=Off + 파라미터>0이면 접근 구간에서 Z를 최종 높이까지 선행 — 지시서 1-A 게이트 명세와 일치하나, 1-B만 끄고 1-A만 쓰는 조합이 가능함을 운영에서 인지 필요.
3. (기존 구조) fixed-Y 드리프트 서브ms 레이스 창, 취소 시 pending 미관찰 잔존(Clear로 정리, 실해 없음) — 기존과 동일 노출, 회귀 아님.
4. 지시서 인용 라인 다수가 구판 기준(정정 목록은 계획 조사 산출물에 보존).
