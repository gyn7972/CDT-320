## 1. 계획 요약

### 발동 지점 확정
`PickerProcessSequence.RunInputCameraMarkInspectionAsync`의 **허가 대기 await를 래핑하는 200ms 폴링 모니터**로 확정. 코디네이터(`WaitForPermissionOrCompletionAsync`)는 무변경 — "허가 대기 상태" 게이트가 모니터 수명 자체로 보장되고, 허가 발행/소비 로직을 건드리지 않는다.
- 대기 세션당 **1회만 발동**(재명령 금지 — AXM 0x1038 선례), 대기 종료(허가/실패/정지) 시 `finally`에서 이동 Task를 join(캡 = `MotionSpeedScale.ScaleDefaultTimeoutMs(15000)`).
- 이동 명령은 시퀀스 토큰 사용(허가 도착으로 모니터가 꺼져도 이동은 완주 후 join).

### 대기점 산식 (기존 재사용 — 신규 산식 없음)
```
waitX = direction > 0 ? constraintVisionX + homeGap − requiredGap
                      : constraintVisionX − homeGap + requiredGap
constraintVisionX = direction > 0 ? min(배치 visionX) : max(배치 visionX)
requiredGap = safetyGap + DynamicWaitExtraMarginMm
(direction/homeGap/safetyGap = service.TryGetFollowGapParameters(pickerX, visionX,
 InputVisionRetreatExtraClearance) — 팔로잉 진입(VisionRetreat.cs:824)과 동일 소스)
```
FollowMoveAsync 간격식(AjinAxis.cs:862)의 항등식 역산으로, 검증에서 양방향 분기 대수 검산 완료. 현행 Input 페어(비전+1/픽커−1 → direction=−1)에서는 max가 구속 극값.

### 배치 좌표·상태 소스 (조사 결과 기존 경로 부재 → 최소 신설 2건)

- `InputCameraPreInspectionCoordinator.IsInspectionRunning(side)`(신규, 읽기 전용): 게이트 ① "촬영 진행 중" 판정.

- `동적 선행 대기점 이동 join 타임아웃 — 백그라운드 관찰로 전환합니다. timeoutMs=…`

실장비 검증 절차:
1. 레시피 페이지(Front/Rear) PICKUP DYNAMIC WAIT **On**(기본 Off), Auto+Conti 런.

4. **블러 확인(B1)**: 같은 웨이퍼에서 스위치 ON/OFF 런의 인풋 비전 보정값(alignOffset) 산포 비교 — ON에서 산포가 유의하게 커지면 blur-safe 모드(범위 제외분) 별도 지시 필요.
