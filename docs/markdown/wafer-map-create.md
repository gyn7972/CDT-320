# 웨이퍼 맵 생성·저장

## 사용 순서

1. **레시피 → 웨이퍼 사양**에서 **INPUT / OUTPUT** 역할을 선택한다.
2. **맵 생성 미리보기**를 열고 외경, 다이 X/Y, GAP X/Y(mm), **내부 여백(mm)**을 확인한다. 내부 여백의 기본값은 **0.200mm**이며 다이 사이의 GAP과 별개다.
3. **AUTO WAFER CREATE**로 원형 맵을 생성한다.
4. 회전은 원본 기준 시계 방향 **0° / 90° / 180° / 270°** 중 선택한다. **현재 장비에서 사용 가능한 각도는 0° / 180°**다. 90° / 270°는 미리보기·설정 저장만 가능하다.
5. 필요한 경우 현재 화면의 상·하·좌·우 맨 끝줄 개수와 **전체 다이 개수**를 지정하고 **개수 적용 / 재생성**을 누른다. 이 버튼은 현재 상단 입력 사양(외경·다이 X/Y·GAP X/Y·내부 여백·회전)도 함께 읽어 새로 계산한다. 행·열은 입력하지 않고 원 사이즈와 개수 조건에서 자동 계산한다.
6. 최종 개수·배치·범위 초과 개수를 확인하고 **SAVE MAP**을 누른다. 빨간 다이가 있어도 초과 다이를 포함한 전체 맵과 생성 조건을 **PENDING 설정으로 저장**할 수 있다. 저장 후 다시 열어도 같은 좌표·개수·초과 표시를 복원한다.
7. 범위 초과가 없는 0° / 180° 맵은 INPUT의 **INPUT DIE MAP CREATE**, OUTPUT의 **BIN DIE MAP CREATE**에서 Target/Skip을 확인한 뒤 **FINAL APPLY**한다. GOOD과 NG는 각각 확인하고 적용한다. 범위 초과 맵과 90° / 270° 맵은 설정 저장까지만 가능하며, 최종 적용과 공정 사용은 차단된다.

상단 사양을 편집해도 직전 미리보기와 입력한 끝줄·전체 개수는 유지된다. 예를 들어 빨간 다이가 있는 상태에서 **WAFER DIAMETER**를 키운 뒤 **개수 적용 / 재생성**을 누르면 입력한 개수를 유지하면서 새 외경으로 배치를 계산한다. 새 결과가 나오기 전에는 직전 결과임을 표시하고 저장을 차단한다. 사양이나 개수 조건이 잘못되어 계산에 실패해도 편집값과 직전 미리보기를 유지하므로 값을 고쳐 다시 적용할 수 있다.

**AUTO WAFER CREATE**는 현재 사양의 기본 원형 맵을 만들고 끝줄·전체 개수 입력도 그 결과로 초기화한다. 회전만 바꾸는 경우에도 해당 각도의 기본 맵으로 돌아가며 개수 보정값이 초기화된다. 사양을 편집 중인 경우에는 회전 변경도 미적용 상태로 유지하고 두 생성 버튼 중 하나로 함께 반영한다. 계산 과정에서 입력 외경·다이 크기·GAP을 자동으로 바꾸지 않는다.

개수 적용 시에는 원 안으로 잘라내기 전의 **전체 후보 격자**에서 다이의 가장 먼 모서리가 원 중심에 가까운 순서로 요청 개수만큼 선택한다. 이 원형 배치가 상·하·좌·우 요청 개수에도 맞으면 그대로 사용한다. 맞지 않으면 X/Y 각각 다이 중심과 GAP 중심에 맞춘 나머지 세 가지 격자 시작 위치도 비교한다. 전체 개수와 네 끝줄 조건을 모두 만족하는 배치만 선택하며, 기본 시작 위치가 맞으면 우선 유지한다. 나머지 조합 중 여러 배치가 맞으면 필요한 반경이 작은 순서와 고정된 조합 순서로 선택한다. 따라서 기본 AUTO에서 빠졌던 맨 위·아래 행도 개수 조건에 따라 다시 포함할 수 있으며, Grid X/Y는 결과로 계산된다.

네 가지 중심 배치 모두 끝줄과 요청값이 다르면 기존 수동 보정 방식으로 네 끝줄을 맞춘다. 기본 맵의 끝줄에서 시작해 필요한 격자를 확장하고, 끝줄부터 중심까지 연속 배치를 확보한 뒤 나머지를 채운다. 끝줄을 연결하는 데 필요한 최소 개수보다 전체 요청이 적으면 그 최소값을 표시한다. **원본 복원**은 마지막으로 생성에 성공한 사양·회전과 그 AUTO 기본 맵으로 돌아가며, 미적용 사양 편집값과 개수 보정을 되돌린다.

사용 가능 반경은 `외경 / 2 − 내부 여백`이다. 다이 중심만 검사하지 않고 실제 다이의 네 모서리까지 이 원 안에 들어오는지 검사한다. 경계에 정확히 닿는 경우는 허용한다. 범위를 벗어난 다이는 빨간색으로 표시하고 초과 개수와 필요한 최소 외경을 보여준다. 필요한 최소 외경은 현재 미리보기 좌표의 다이 전체를 감싸는 원에 설정 여백을 더한 계산값이며, 입력 외경을 자동 변경하지 않는다. 외경을 바꿔 다시 생성하면 후보 격자와 시작점도 달라질 수 있으므로 결과 배치와 초과 여부를 다시 확인한다. 빨간 다이도 설정 저장에는 포함되지만, 실제 사용하려면 초과가 없도록 조건을 수정하고 다시 저장한 뒤 FINAL APPLY해야 한다.

예를 들어 생성 결과가 730개이고 그중 21개가 빨간색이면 **730개 전체가 저장**된다. 21개를 삭제하거나 Skip으로 바꾸지 않는다. 사양·개수 편집이 아직 미적용이거나 계산 자체가 실패한 상태의 저장 차단은 유지한다.

미리보기의 다이 크기는 자유롭게 시험할 수 있지만, 저장할 때는 레시피의 공통 **다이 사양**과 같아야 한다. 제품의 다이 크기를 바꾸려면 먼저 다이 사양을 저장한다.

## JMB 배치 기준

외경 **287.640mm**, 다이 **8.070 × 6.070mm**, 내부 여백 **0.200mm**, 회전 **0°** 기준이다. AUTO로 기본 맵을 만든 뒤 아래 개수 조건을 넣고 **개수 적용 / 재생성**한다. Grid는 직접 입력하지 않는다.

| 역할 | GAP X / Y (mm) | 전체 개수 | 상 / 하 | 좌 / 우 | 결과 Grid X / Y |
|---|---|---:|---|---|---|
| INPUT | 0.050 / 0.050 | 1,257 | 3 / 3 | 9 / 9 | 35 / 47 |
| OUTPUT | 0.300 / 0.300 | 1,142 | 2 / 2 | 7 / 7 | 34 / 45 |

이 두 조건은 JMB의 `YZ9XFA3.13.txt` 기반 INPUT 및 `PLACE_WAFER_1142.txt` 기반 OUTPUT의 물리 배치 좌표와 비교한다. INPUT의 BIN 색상·검사 결과는 외부 파일에서 읽는 데이터이며 자동 생성 시 임의로 재현하지 않는다.

현재 내부 여백 기준으로 INPUT은 38개, OUTPUT은 4개가 초과로 표시된다. 초과 다이를 포함한 전체 배치 저장은 가능하며 최종 적용 제한은 유지된다. 이 수량만 보고 Grid를 늘리거나 입력 외경을 자동으로 바꾸지 않는다.

## RKE OUTPUT 배치 기준

외경 **287.640mm**, 다이 **10.370 × 7.913mm**, GAP **0.300 × 0.300mm**, 회전 **0°**에서 전체 **684개**, 상/하 **6/6**, 좌/우 **8/8**을 넣고 **개수 적용 / 재생성**한다. 내부 여백은 **0.000mm 또는 0.200mm**에서 모두 원본과 동일한 **26×34** 배치와 **초과 0개**가 된다.

RKE는 X/Y 모두 GAP 중심에 맞는 배치다. Y의 중앙 두 행은 **−4.1065mm / +4.1065mm**이며, 기존의 Y=0 중심 행을 가진 26×33 배치와 다르다. 외경이나 Grid를 직접 바꿔 맞출 필요가 없다. JMB INPUT은 X/Y 다이 중심, JMB OUTPUT은 X GAP 중심/Y 다이 중심이 선택되어 기존 좌표를 유지한다.

이전에 저장한 잘못된 RKE 26×33 맵은 열기만 해서는 바뀌지 않는다. 저장된 사양과 위 개수 조건을 확인하고 **개수 적용 / 재생성 → SAVE MAP**을 실행한 뒤 **BIN DIE MAP CREATE**에서 GOOD/NG를 각각 확인하고 FINAL APPLY한다.

## 저장 및 표시

| 역할 | 저장되는 맵 | 저장 후 승인 |
|---|---|---|
| INPUT | InputBaseWaferMap, InputDieMap | INPUT PENDING |
| OUTPUT | OutputBaseWaferMap, GoodBinDieMap, NgBinDieMap | GOOD / NG PENDING |

생성 조건, 내부 여백, 회전, 끝줄·전체 개수 보정값을 JSON/CSV에 함께 보관한다. 다시 미리보기를 열면 저장된 결과를 복원한다. 사양 화면에서 외경이나 GAP을 편집한 상태로 열면 그 편집값을 우선하며 다시 생성해야 한다.

웨이퍼 사양의 **Grid X/Y**는 저장된 맵이 차지하는 실제 행·열 범위이며 읽기 전용이다. 다이 개수는 별도로 표시한다. 예를 들어 격자 26×34 안에 실제 다이 684개가 있을 수 있다. 외경은 0.001mm까지 표시한다.

상단 SAVE는 생성 맵의 형상을 바꾸지 않는다. 생성 맵의 외경·다이·GAP·내부 여백·회전 변경은 미리보기에서 다시 생성하고 저장한다. 기존 **LOAD WAFER MAP**은 외부 파일을 가져오는 경로로 유지한다. 기존 GRID MAP CREATE 버튼은 사용하지 않는다.

새 맵 저장은 현재 레시피의 기존 운전·자재 보호 조건을 통과한 뒤 실행된다. 현재 wafer, Teaching, 축 좌표를 직접 변경하거나 장비를 움직이지 않는다. 저장만으로 맵이 승인되지는 않는다. 범위와 회전 조건을 통과한 맵만 해당 역할의 FINAL APPLY 확인을 거쳐 기존 공정 경로에서 사용한다.

## 계산 및 연결 기준

- 기본 후보 격자와 시작점은 `BINMAP CREATE VIEWER`의 `CreatedBinMap`, `MapCountEnable=false`, `Zigzag=false` 분기를 기준으로 한다.
- 입력·표시·저장은 mm, 기본 격자 계산은 원본 정수 µm 나눗셈 절사를 보존한다. 다이 반폭·반높이는 0.0005mm도 보존하여 실제 모서리를 검사한다.
- 중심 간격 = 다이 크기 + GAP. 새 생성 방식은 내부 여백을 뺀 반경과 실제 다이 모서리로 유효 여부를 판정한다.
- 개수 보정은 기본 맵에서 매번 다시 계산한다. 범위 밖 다이도 미리보기와 설정 저장에 그대로 포함한다. 하나라도 초과하면 FINAL APPLY·승인·공정용 맵 로드·MaterialSpecs 적용을 차단한다.
- 저장용 검증은 경계 초과만 허용한다. 생성 정의와 실제 셀의 주소·좌표·격자·개수 정합 검증은 그대로 유지한다. 잘못되거나 누락된 생성 조건을 저장 가능한 맵으로 간주하지 않는다.
- 회전해도 원본 다이 주소는 유지한다. 현재 방향의 local index, 물리 다이 크기, 중심 간격만 함께 변환한다.
- 미리보기는 +Y가 위, 장비 맵은 기존 엔코더 방향에 맞춰 `PosY = -previewY`로 저장한다. 저장 과정에서 사용 격자 중앙으로 재정렬하지 않는다.
- Recipe의 다이·GAP 설정은 원본 방향으로 보관한다. MaterialSpecs에 전달하기 전 저장 맵과의 정합 및 지원 각도를 검사하며, 90° / 270°는 사양 적용을 차단한다.

이전 버전 저장 맵은 기존 수식(피치 셀 모서리, 반경 +0.200mm)으로 그대로 복원한다. 이 경우 화면에 이전 방식의 외곽 여유임을 구분해 표시한다. AUTO WAFER CREATE로 다시 생성하거나 상단 사양을 편집한 뒤 개수 적용 / 재생성을 실행하면 새 내부 여백 방식으로 전환된다. 기존 저장 맵이나 외부 파일을 새 내부 여백 기준으로 자동 변환하지 않는다.

저장 버전 2의 수동 개수 보정과 버전 3의 고정 시작 위치 배치는 당시의 형상 그대로 복원한다. 새 AUTO와 개수 적용은 버전 4로 생성하며, 개수 적용에서 전체 후보 격자의 네 가지 중심 배치를 비교한다. 저장된 생성 조건으로 같은 배치를 다시 계산할 수 있고 이전 저장 파일을 열기만 해서는 배치가 바뀌지 않는다. 회전 변경과 원본 복원은 이전과 같이 기본 AUTO로 돌아가므로, 보정 배치를 다시 만들려면 해당 방향의 끝줄·전체 개수를 적용한다.

이전 참고 수식의 회귀 기준: 다이 10.370×7.913mm, GAP 0.300×0.300mm에서 외경 287.400mm는 **684개**, 외경 287.640mm는 **682개**다. 새 방식은 판정 기준이 바뀌었으므로 이 수량을 목표로 강제하지 않는다. 개수 지정 배치는 공통 보정 규칙으로 계산하는 기능이며, 업체의 원본 생성 수식과 동일하다고 보장하는 기능은 아니다.

## 검증 도구

- `tools/verify_wafer_map_generation.ps1`: 원본 수식, 절대 회전, 끝줄 보정.
- `tools/verify_generated_wafer_persistence.ps1`: JSON/CSV 왕복, 좌표 정밀도, 생성 정의 검증, 기존 런타임 맵 호환.
- `tools/verify_wafer_map_storage.ps1`: 역할별 저장·승인·Target/Skip, 복원, 외부 파일 가져오기.
- `tools/verify_wafer_map_dialog.ps1`: 독립 WinForms 다이얼로그와 실제 부모 이벤트의 UI 검증.
- `tools/verify_generated_map_save_guard.ps1`: 실제 저장 coordinator와 대체 장비/파일 경계로 저장 전 보호·실패 동작 검증.
- `tools/verify_generated_frame_projection.ps1`: 맵·사양 정합, 미지원 각도 차단, 원본 사양 보존, Input/Output 사양 동기화.

독립 검증과 별도 출력 폴더 빌드는 실장비 시험을 대신하지 않는다. 현장에서는 역할별 생성·저장·재열기, 회전 후 맵 확인, FINAL APPLY 및 기존 정렬 절차를 확인한다.

## 현재 장비의 회전 제한

사용자 확정: 90° / 270°는 현재 장비에 맞지 않으므로 선택·미리보기·설정 저장까지만 제공한다. INPUT과 OUTPUT 모두 FINAL APPLY, 공정용 맵 로드, 승인 확인 및 MaterialSpecs 적용에서 차단한다. 이미 승인된 것으로 기록된 맵도 이 제한을 통과할 수 없다.

픽커의 비전 Y 허용범위와 Side 카메라 Y 목표의 치수 참조는 변경하지 않았다. 기존 외부 맵과 생성 맵 0° / 180°는 기존 검사 계산식을 사용한다.
