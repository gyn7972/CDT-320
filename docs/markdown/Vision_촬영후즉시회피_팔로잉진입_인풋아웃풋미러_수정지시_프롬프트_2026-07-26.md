## 1. 목표 동작 (사용자 확정 설계)

### 1-A. 인풋 비전 (선행검사) — 독립 촬영·즉시 회피

```
자기 픽업 완료 → 선행검사 세션 시작 (기존 트리거 유지)
→ die별: 촬영 위치 이동 → 도달 즉시 촬영(EPD) → 다음 die
→ 배치 마지막 die EPD 완료 "즉시" InputVisionX가 스스로(비동기) 회피 이동 시작
   - 회피 목표 = 다음 픽업 픽커의 X 최대 접근 위치 + 기존 인풋 클리어런스 (기존 최소회피 근사 산출 재사용)
   - 산출 불가 시 = Avoid 위치까지
→ 픽업 허가 발행은 회피 완료를 기다리지 않는다 (기존 조기허가 구조 유지)
```
**핵심 변경**: 현재의 "회피를 픽업 이연·팔로잉으로 위임(이동 생략)" 홀드 설계를 폐지한다.
실측 근거(2026-07-25 런): 8사이클 전부 촬영 위치 홀드 2.1~36.0초 + 픽커 진입 명령과 동일 ms에야 회피 시작 + 픽커가 진입 후 회피 완료를 5.7~6.7초 추가 대기(픽업 크리티컬 패스 포함).

### 1-B. 픽업 픽커 X 진입 — 3단계 규칙

| 비전 상태 | 픽커 동작 |
|---|---|
| 회피 완료 (일반적) | 대기 0으로 즉시 진입 |
| 회피 이동 중 | FollowMove(모션 오버라이드)로 안전거리 유지하며 비전 꽁무니를 따라 진입 — 회피 완료를 기다리지 않음 |
| 아직 촬영 중 (드묾) | 배치 마지막 촬영(EPD) 완료까지만 대기 → 회피 시작과 동시에 팔로잉 진입 |

### 1-C. 아웃풋 비전 (후검사) — 인풋과 미러

```
픽커가 Place를 끝내고 빠지기 시작 → OutputVisionX가 팔로잉으로 따라 들어가 촬영 (기존 유지)
→ 배치 마지막 die EPD 완료 "즉시" OutputVisionX가 스스로(비동기) 회피 이동 시작
   - 회피 목표 = 다음 Place 픽커의 X 최대 접근 위치 + 인풋과 동일한 클리어런스 산식(미러)
   - 산출 불가 시 = Avoid 위치까지
→ RESULT 수집은 회피와 병렬(기존 유지), Place 진입을 막지 않는다
```

### 1-D. Place 픽커 X 진입 — 1-B와 동일한 3단계 규칙 (미러)

| 비전 상태 | 픽커 동작 |
|---|---|
| 회피 완료 | 대기 0 즉시 진입 |
| 회피 이동 중 | FollowMove로 따라 진입, 회피 완료 대기 금지 |
| 아직 촬영 중 | 배치 마지막 EPD 완료까지만 대기 → 회피 시작과 동시에 팔로잉 진입 |

### 1-E. Picker Motion Only Test 모드 — 무변경

- 인풋: 스테이지만 이동, InputVisionX 이동·촬영 생략, 보정 0 (현행 유지)
- 아웃풋: 후검사 등록 차단 (현행 유지)
- 사용자 확정: "모션 온리면 안 찍는 게 맞다." 이 모드의 게이트 로직은 이번 수정에서 건드리지 않는다.

## 3. 수정 지점 후보 (계획 단계에서 확정할 것)

### 인풋
1. **I1 위임 분기 폐지 → 즉시 비동기 회피**: InputCameraMarkInspectionSequence.cs:500-508에서 "이동 생략" 대신 배치 마지막 EPD 직후 최소회피 이동을 fire-and-forget 비동기 시작하고, 회피 Task/목표를 공유 상태로 노출한다. GrantPickUpPermission은 회피 완료를 기다리지 않고 발행(기존 조기허가 유지).
   - 회피 목표: 기존 근사 산출(I2) 재사용. 산출 불가 시 Avoid.
2. **I3 이연 플래그 → 외부 회피 인식**: 픽업의 MoveInputVisionToAvoidForPickerMoveAsync는 (a) 외부(선행검사)가 이미 회피를 시작했으면 그 Task/목표를 인수하고, (b) 외부 회피가 없을 때만(예: 근사≠정확 좌표 차이로 추가 후퇴 필요) 자체 회피를 즉시 비동기 기동한다. "픽커 진입 시점까지 이연"은 폐지.
3. **I5 팔로잉 조건 확장**: ShouldFollowInputVisionRetreatForPickerEntry가 시퀀스-로컬 필드 외에 "외부 회피 진행 중(공유 상태 + CameraX.IsMoving + 회피 목표)"을 인식하도록 확장. 공유 매체는 SharedRailXMotionService 계열 기존 구조 활용을 우선 검토.
4. **I7 허가 소비 검증 완화(핵심 동반 항목)**: IsInputVisionParkedClearOfPickers에 "회피 목표를 향해 이동 중"을 통과 조건으로 추가. 단, 회피가 아닌 방향(촬영 위치로 접근 중 등)의 이동은 여전히 false.
5. **3단계-③(아직 촬영 중) 처리**: 픽업 준비가 배치 촬영 완료보다 빠른 경우 → 배치 마지막 EPD 완료 신호까지만 대기 후 회피 시작과 동시에 팔로잉 진입. (현 구조상 허가 발행이 배치 종료 직후이므로 "허가 대기"가 자연스럽게 이 역할을 하는지 계획 단계에서 확인하고, 아니라면 EPD 완료 신호 대기를 명시 구현.)

### 아웃풋 (인풋과 미러)
6. **O3 회피 목표 변경**: 배치 EPD 완료 즉시 회피는 유지하되, 목표를 "다음 Place 픽커 X 최대 접근 위치 + 인풋과 동일 클리어런스 산식(미러)"로 변경. 다음 Place 배치 좌표를 알 수 없으면 기존대로 Avoid. RESULT 수집 병렬 유지.
7. **O4 확장 — Place 진입 3단계**: 기존 R4/O-2 이연 구조를 "외부(후검사 큐) 회피 인식 + 3단계"로 확장 (인풋 2·3·4번의 미러). Place 진입용 "비전 정지/Avoid 전제" 검증이 있으면 I7과 동일하게 "회피 방향 이동 중" 통과 조건 추가.
8. **OutputPlaceArea lease 핸드오버**: 다음 Place가 3단계 진입을 하려면 후검사 워커의 OutputPlaceArea lease가 "배치 EPD 완료 + 회피 시작" 시점에 반환되어야 한다. 현재 반환 시점을 계획 단계에서 확인하고, RESULT 수집 완료까지 잡고 있으면 반환 시점을 앞당긴다 (RESULT 수집은 lease 없이 진행 가능해야 함).

### 공통
9. 새 분기/이동에는 기존 규약대로 로그 추가 (기존 로그 문구는 유지·확장, 삭제 금지).
10. 시퀀스 실패/CycleStop 시 비동기 회피 Task의 정리(join/취소) 경로를 명시 구현 — 미정리 Task가 다음 배치와 겹치지 않게.

## 5. 금지·제약 사항

1. **MotionSpeedScale**: 신규·수정되는 모든 이동 명령(회피, 팔로잉, 양보 이동)에 공정 속도 스케일 적용 필수. 스케일 미적용 이동 코드를 발견하면 수정하지 말고 레포트에 보고. 타임아웃 계산에도 스케일 반영(C2).
2. **인터락 판정 로직 완화 금지**: A그룹 인터락 본체는 한 줄도 수정 금지. B그룹은 "회피 이동 중 상태의 인식 추가"만 허용.
3. **PlaceRuntime 오프셋 필터 Enable 금지**, 후검사 X +1.15 관련 상수/로직 무변경 (측정 기준 상수 — 사용자 방치 결정).
4. **Motion Only 게이트 무변경** (1-E). 부수적으로 발견된 "RunStart 잔여 후검사 복구 경로가 Motion Only 게이트를 안 탐"(OutputPostPlaceInspectionQueue.cs:421-443) 이슈는 이번 범위 제외 — 레포트에 별도 이슈로만 기재.
5. M8 원자 예약·드레인·페이즈 코디네이터·CycleStop 경계(M7) 로직 무변경.
6. 기존 로그 문구 삭제 금지. 신규 분기에는 기존 규약(WriteLog 태그 체계) 로그 추가.
7. 촬영 요청 발신 경로(I9)와 결과 회수 이연 구조(픽업 CalculatePickTargets에서 RESULT 회수) 무변경 — 이번 수정은 "회피 타이밍과 진입 방식"만 바꾼다.
