### 인터락 면제 설계 — 신규 토큰 `PickUpZHold={pickerNo}` (승인 조건 그대로)

- **성립 조건(공용 헬퍼 1곳 고정)**: 토큰 + `InspectionZHold` + `InspectionContinuous` + **PickerZone/From/To 전부 Input** + Auto 계열 이동(티칭무브/팔로잉 오버라이드) + pickerNo 1~4
- **발행처 유일**: 시퀀스 `BuildPickMoveTargetName` 1곳(전수 grep 증명) — 발행 게이트(Auto+die간+hold활성) × hold 등록 게이트(스위치 On+Auto+**Conti**+PrePick거리>0+다음 die 존재+**현재/다음 die 모두 반경 내**)로 승인 조건 완성
- **면제 범위**: 유지 픽커 Z **하나의 위치 요구만** — 비이동 요구 유지, 나머지 3개 픽커 Z 요구 전부 기존 그대로. 토큰 없으면 모든 룰이 기존과 완전 동일(diff 0 증명)
- **적용 지점** (조사로 확정한 차단점 전수, Front/Rear 미러): ①Auto X `Z전축AvoidForMove` ②Input 진입 `AvoidOrNonNegative` ③존 공용 `HomeOrAvoidForInputZone`(X/Y) ④팔로잉 오버라이드 `HomeOrAvoid` ⑤Y 유닛 룰(2회차 수정분)
- **기존 InspectionZHold(Bottom/Side/Output) 화이트리스트 무변경** — 광역 확장이 아니라 별도 토큰

### hold 메커니즘 (시퀀스)
- 픽업 후 상승을 PrePick에서 끊고 유지 → 다음 die의 XYT/Y가 토큰 면제로 통과 → **핸드오버**: 다음 die 픽업 완료 시 이전 유지 Z를 Avoid 완전 복귀 후 새 hold
- 마지막 die/반경 밖: hold 미생성(기존 경로) → 배치 종료 시 전 Z Avoid 수렴
- die 진입 Z 강제복귀: 유지 축만 제외 + **파킹 불일치 시 자가치유**(hold 해제+전체 Avoid 폴백)
- 드레인 경계: `DrainLeftPickerZHoldUnsafe` 기록 → ProcessSequence가 Bottom Full-Avoid 생략 해제 → Bottom 첫 스텝이 잔류 Z 정상 회수(신규 이동 0)

## 3. 체크리스트 결과 (회차별)

**1-A+반경 게이트 (1회차)**: 49/49 PASS, FAIL 0 — F1~F8/L1(A1~A8)/L2(B1~B6)/L3/R1~R4 전부. 보강 1건(발행~join 사이 Fail 시 stale task — 새 die 진입 전 정리 1줄).

**1-B (1회차)**: 36항목 중 FAIL 3(실질 2) —
- E5/커버리지: **Y 유닛 룰 미면제** — hold 중 die 간 Y 보정이 차단·알람(결정적) → Front/Rear CanManualPickerY에 Except 변형 스레딩
- S5: **드레인 경계 hold 잔류** — Z가 PrePick에 남은 채 배치 종료 → Bottom 진입 알람 → unsafe 플래그 + Bottom Full-Avoid 생략 해제(동기 스텝 유지, 신규 이동 0)

**1-B (2회차)**: R1(E5 수정)/R2(S5 수정)/R3(기존 PASS 무회귀) **3/3 PASS, FAIL 0 — 종결**

## 5. 별도 이슈 (범위 외)

1. 지시서 인용 라인 다수 구판 기준(파일 분할 전) — 실위치는 본 레포트/검증 근거 기준.
2. 기존 반경 값 실체: 코드 폴백 125mm(Setup 값이 우선) — "150"은 장비 Setup 영속값/비전용 반경일 가능성. 신설 게이트는 런타임 반경으로 자동 클램프하므로 안전.
3. 이론적 엣지(방치 가능 판정): 드레인 unsafe + 보유 die 없음 조합은 실질 도달 불가, 도달해도 기존 인터락이 fail-safe.
4. pre-down 명령 비취소성(CycleStop 후 PrePick까지 하강 완료) — conti 기존 prePick과 동일 부류, 다음 시퀀스 초입 Z Avoid로 정리.
