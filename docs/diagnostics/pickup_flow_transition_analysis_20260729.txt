4. 현재 자동 PickUp의 Needle-Picker 인계 흐름

1) Input Vision RESULT로 다음 목표를 계산한다.
2) StageY, NeedleX, PickerX/Y/T를 Pick 위치로 이동한다.
3) PickerZ를 PrePick 위치까지 이동한다.
4) Picker Vacuum을 ON한다.
5) PickerZ를 Die Touch 위치까지 이동한다.
6) Touch 위치에서 VacuumOnBeforePickDelayMs만큼 기다린다.
7) PickerZ와 EjectPinZ를 PickUpNeedleSyncLiftDistance만큼 동시에 상승시킨다.
8) NeedleZ는 기존 Teaching 위치를 유지한다.
9) 동기 상승 완료 후 PickUpNeedleSyncLiftSettleMs만큼 기다린다.
10) Flow 확인 Task를 시작한다.
11) 현재 Separate Step은 제거되어 PickerZ를 바로 Avoid 방향으로 상승시킨다.
12) PickerZ가 PickerSafeForWaferStageDistance 이상 상승하면 Needle Vacuum을 OFF하고 EjectPinZ를 복귀시킨다.
13) Flow 확인이 완료되지 않았더라도 현재 코드는 다음 Step으로 진행할 수 있다.
14) Material 데이터를 Picker로 이동한다.
15) Bottom/Side 검사 시작 전 실제 Flow를 다시 확인한다.


5. 현재 실제 적용되는 딜레이

5.1 VacuumOnBeforePickDelayMs

- Front: 100ms
- Rear: 100ms
- 실제 용도:
  PickerZ가 Die Touch 위치에 도착하고 위치 확인이 끝난 후 Sync Lift 전 대기한다.
- UI:
  Front Head 또는 Rear Head
  -> PICKUP SETTING
  -> VACUUM BEFORE PICK DELAY
- 설정 파일:
  D:\CDT-320\EquipmentData\Config\PickerFrontUnit.json
  D:\CDT-320\EquipmentData\Config\PickerRearUnit.json

5.2 PickUpNeedleSyncLiftSettleMs

- Front/Rear 공통: 30ms
- 실제 용도:
  PickerZ와 EjectPinZ 동기 상승 완료 후 대기한다.
- UI:
  Input Stage
  -> NEEDLE PICKUP SETTING
  -> PICKUP SYNC LIFT SETTLE
- 설정 파일:
  D:\CDT-320\EquipmentData\Config\InputStageUnit.json
- 주의:
  Picker Front/Rear 화면의 SYNC LIFT SETTLE보다 InputStage 공통값이 우선 적용된다.

5.3 PickSettleMs

- Front: 0ms
- Rear: 0ms
- 실제 용도:
  PickUp Z 동작 후 Flow/Material 갱신 전에 적용할 수 있는 추가 안정화 대기다.
- 현재값이 0이므로 실제 추가 대기는 없다.
- UI:
  Front Head 또는 Rear Head
  -> PICKUP SETTING
  -> PICK SETTLE

5.4 NeedleVacuumOffSettleBeforeXYMs

- Front: 20ms
- Rear: 10ms
- 실제 용도:
  Needle Vacuum OFF 후 StageY/NeedleX 이동을 허용하기 위한 최소 경과시간이다.
- OFF 이후 이미 경과한 시간을 차감한다.
- 예:
  Vacuum OFF 후 56.9ms가 이미 지났고 설정이 20ms이면 추가 대기는 0ms다.
- UI:
  Front Head 또는 Rear Head
  -> PICKUP SETTING
  -> NEEDLE VACUUM OFF SETTLE

  -> PICKER Z PRE PICK DISTANCE

6.2 PickerZSlowApproachSpeedPercent

- Front: 100%
- Rear: 100%
- 실제 용도:
  PrePick에서 Die Touch 위치까지의 최종 PickerZ 접근 속도 비율이다.
- UI:
  Front Head 또는 Rear Head
  -> PICKUP SETTING
  -> PICKER Z APPROACH SPEED

6.3 PickUpEjectPinOffset

- 현재값: 0mm
- 실제 용도:
  EjectPinZ Pick Teaching 위치에 더하는 Offset이다.
- UI:
  Input Stage
  -> NEEDLE PICKUP SETTING
  -> EJECT PIN PICK OFFSET

6.4 PickUpNeedleSyncLiftDistance

- 현재값: 0.6mm
- 실제 용도:
  PickerZ와 EjectPinZ가 동시에 상승하는 공통 거리다.
- 계산:
  PickerZ 목표 = PickerZ Die Touch 위치 + 0.6mm
  EjectPinZ 목표 = EjectPinZ Pick 위치 + 0.6mm + EjectPin Sync Offset
  NeedleZ 목표 = 기존 Teaching 위치 유지
- UI:
  Input Stage
  -> NEEDLE PICKUP SETTING
  -> PICKUP SYNC LIFT DISTANCE

6.5 PickerSafeForWaferStageDistance

- Front: 2mm
- Rear: 2mm
- 실제 용도:
  PickerZ가 Die Touch 위치에서 Avoid 방향으로 2mm 이상 상승하면 Stage 관련 다음 동작을 허용한다.
- 이동 목표가 아니라 다음 동작 허용 기준 거리다.
- UI:
  Front Head 또는 Rear Head
  -> PICKUP SETTING
  -> PICKER SAFE FOR WAFERSTAGE

6.6 PickerZSeparateSpeedPercent

- Front: 100%
- Rear: 100%
- 실제 용도:
  현재 코드에서는 PickerZ/EjectPinZ의 0.6mm 동기 상승 속도 비율로 사용한다.
- 속도 모델:
  각 축 기본속도 x 전역 속도 스케일 x PickerZSeparateSpeedPercent
- 현재 UI에는 노출되지 않는다.
- 설정 파일에서만 확인 가능:
  D:\CDT-320\EquipmentData\Config\PickerFrontUnit.json

8. 향후 로그 분석 방법

PickUp 실패가 발생하면 다음 순서로 확인한다.

1) 해당 Die와 Picker 번호를 찾는다.
2) Picker Vacuum ON 시각을 찾는다.
3) PickerZ Touch 완료 시각과 위치를 찾는다.
4) PickerZ/EjectPinZ Sync Lift 시작/완료 시각을 찾는다.
5) PickerFlowTransition의 최초 ON 시각을 찾는다.
6) 최초 ON 이후 OFF 전이가 있는지 찾는다.
7) OFF 전이 순간 PickerZ/EjectPinZ actual/command/moving을 확인한다.
8) Bottom/Side 시작 전 Flow 확인 결과와 연결한다.

판정 기준:

A. Flow가 한 번도 ON되지 않음

- 실제 Pick 미흡 가능성
- Vacuum 공급/콜렛 막힘/누설
- PickerZ Touch 높이
- Die 중심 위치
- EjectPinZ Pick 높이
- Contact 후 100ms 응답 시간 확인

B. Flow가 Sync Lift 중 OFF로 전이

- PickerZ/EjectPinZ 동기 상승 조건 확인
- Sync Lift 거리 0.6mm 확인
- 동기 상승 속도 비율 100% 확인
- PickerZ와 EjectPinZ의 실제 이동 완료 시차 확인
- 테이프 장력 및 Die 분리 저항 확인

C. Flow가 PickerZ Avoid 상승 중 OFF로 전이

- Separate Step 제거 영향 가능성
- PickerZ Avoid 상승 속도/가속도 영향 가능성
- Die가 완전히 분리되기 전 급상승하는지 확인
- 콜렛 중심 및 진공 유지력 확인

D. PickerZ가 정지한 뒤 Flow가 OFF로 전이

- 진공 누설
- 콜렛 오염/손상
- Die가 콜렛 중심에서 벗어난 상태
- Die 흔들림
- Vacuum 밸브/센서 채터링

E. ON/OFF가 짧은 시간에 반복됨

- Flow 센서 채터링
- Vacuum 압력 임계값
- 튜브/피팅 누설
- 콜렛 접촉면 불안정
- 전이 간격을 10ms 단위로 비교한다.
