- [x] 공통 정책에서 중복 UID/index·일직선·점 부족·대응 근거 누락의 거부를 독립 테스트했다. 실제 대응 여부는 현장에서 확인해야 한다.
- [x] 검증점 삼각형의 최소 높이/최장 변 비율 0.1 이상을 Review 점 배치 조건으로 적용하고 거의 일직선인 조합, 회전·축척·반전·순서 변경을 정책 테스트했다. 이는 OFFSET 한계나 생산 정밀도 허용치가 아니다.
- [ ] 이동 전에 점 배치 오류를 알리고, 남은 실제 다이가 3개 미만이거나 한 줄뿐인 경우를 합격으로 우회하지 않는다.

- [ ] XY/T/pitch 허용치의 출처·단위·실제 적용값을 기록한다.
- [ ] Review의 측정 피치 불일치는 재검출/설정 확인으로 처리하며 설정값 대체 또는 자동 레시피 수정으로 합격시키지 않는다. 기존 Auto Align의 피치 계산·대체·분기는 변경하지 않는다.

- [ ] 검증 후 candidate 좌표·원점·T·pitch·레시피 조건이 바뀌면 승인이 무효가 된다.
- [ ] 기본 순서 자동 승인/Simulation/저장 상태 복구 경로에서 실제 운전용 검증을 우회하지 않는다.
- [ ] 저장 실패·취소·예외 시 승인 및 정상 준비 신호를 발행하지 않는다.

- [ ] 검출 후 수동 위치·선택 기준 변경에는 일관되게 재검출을 요구한다.
