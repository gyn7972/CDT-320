# RAD 웨이퍼맵 수량 검증 체크리스트

기록일: 2026-09-07. `01-implementation-prompt.md`에 따른 구현, 실제 파일·합성 입력 회귀, 정적 검토, 격리 빌드 결과를 기록한다. 최종 회귀 78/78건(합성 55건 + 실제 파일 23건)과 전체 솔루션 격리 빌드는 통과했다. 현장 통신·정렬·픽업은 미수행이며 임시 빌드 출력 정리는 자동 승인 정책에 의해 차단되었다.

이 정책은 현재 로컬 RAD 파일군의 실제 레코드 검증에 근거한다. `%`와 `&`의 공식 포맷 사양을 확보했다는 뜻은 아니며, `&`를 기준점 수나 EOW 수로 해석하지 않는다.

이 문서의 “전체 검증 성공 후 경고”는 파서 내부의 레코드 수·중복 좌표·맵 정규화 검증 완료를 뜻한다. 원격 서비스의 피치·선택 BIN 등 후속 검증은 기존 흐름을 유지하므로, 파서 성공만으로 실제 장비 작업 진행이 확정되지 않는다.
