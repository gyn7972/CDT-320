3. Picker 안전 복귀
------------------
[x] PICK-001 | 정상 Cycle Stop 중 Place 완료 복귀가 Z→Y→X/T 순서를 유지한다.
    결과/근거: 기존 Place 복귀 순서 유지, 최종 보강은 기존 Z→Y→X→T 전체 Avoid 메서드 재사용
[x] PICK-002 | 정상 Cycle Stop 최종 PickerX 목표가 동적 대기점이 아닌 고정 Avoid다.
    결과/근거: 동적 목표 판정 전·후 Cycle Stop 경합을 모두 고정 Avoid로 확정
[x] PICK-003 | Front/Rear Picker가 각각 X/Y/T/Z 전체 Avoid 위치를 확인한다.
    결과/근거: 각 활성 Picker Process에서 EnsureSelfFullSafeAsync 실행 후 Coordinator가 양쪽 전체 Avoid/정지를 재확인
[x] PICK-004 | 안전 복귀 중 Cycle Stop 경계 예외가 X 이동을 중간 절단하지 않는다.
    결과/근거: RunSafetyRetreatMoveAsync가 안전 복귀 구간의 Cycle Stop 경계 polling만 보류함
[x] PICK-005 | Picker Process 리소스와 phase는 전체 안전 복귀 확인 후 반환된다.
    결과/근거: 정상 Auto Cycle Stop finally에서 전체 안전 복귀 이후 Process/phase 반환
[x] PICK-006 | Picker Avoid 실패가 성공 CycleStopped로 바뀌지 않고 Alarm으로 전파된다.
    결과/근거: 안전 복귀 실패는 일반 예외로 Coordinator 상위 MachineController 실패 경로에 전파됨

10. 현장 검증 시 주의
-------------------
- 첫 검증은 저속/Fine 조건과 충돌 감시가 가능한 상태에서 수행한다.
- 정상 STOP 버튼만 사용하고 EMO/Alarm 정지 결과와 혼합하지 않는다.
- 축 Actual/Command/IsMoving, Picker Die 보유 상태, Output inspection pending 수를 함께 기록한다.
- 이상 발생 시 재시작하지 말고 해당 시점 로그와 Material/축 상태를 먼저 보존한다.
